# Deep Funding: First Public Vertical Slice

Timestamp: 2026-09-05, Asia/Shanghai. Source: Pengyi's Deep Funding build brief and two-sided agent clarification.

## Mission Preserved

Company wants the right capital; capital wants the right company. Agents perform Information → Analysis → Audit → Match before humans enter introductions, meetings and diligence. This is broader than a funding contact list.

## Implementation

New isolated `deep-funding` repository; React/TypeScript frontend, Worker API and D1. Company and Funding each have four deterministic, typed agent responsibilities. Matches preserve both profile revisions, evidence snapshots, weighted dimensions, hard-failure reasons and versioned A2A messages. UI covers all founder/funder routes, match detail, trace, JSON export and human handoff records.

Only synthetic profiles were used. The public sandbox does not import private funding repository contents, contacts, credentials or real deal materials. Optional model/provider interfaces are separated from authoritative decisions and clearly inactive. Public demo sessions expire and can be deleted.

## Findings During Build

- A high-score incomplete mandate tied a ready mandate. Browser verification caught the incorrect first recommendation. Decision priority now precedes score in one shared comparator, with a regression case.
- Evidence references are side-qualified, with duplicate and cross-side field validation.
- Human-request inserts and trace appends are transactional and idempotent. Matching profile revisions are rechecked during insertion.
- Private notes/restricted evidence are excluded before agent matching; current evidence and hard constraints are re-evaluated before introduction requests.

## Measurements

34 unit tests and four local browser/API suites passed. Four production suites passed against Cloudflare, including onboarding, persisted handoffs, source-version staleness and isolated workspace access. The fixed five-case benchmark compares a score-only baseline (two false introduction eligibilities) with gated decisions (zero in that constructed set). No real-world funding prediction claim follows from it.

## Next

Verified accounts and consent are prerequisites to any real directory or cross-party matching. Semantic retrieval/model adapters require a labeled benchmark, prompt-injection tests, source grounding, latency/cost measurements and explicit version decisions. Real email introductions and data rooms stay disabled until separately implemented and authorized.
