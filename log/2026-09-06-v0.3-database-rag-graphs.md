# Deep Funding V0.3: Private Database and Public Knowledge

Started: 2026-09-06, Asia/Shanghai.
User direction: execute DEEP_FUNDING_V0.3_DATABASE_RAG_GRAPH_CODEX.md; after V0.3,

## Implemented

Added the requested Python/SQLite persistence layer without replacing the V0.2
React/Worker/D1 sandbox or local-first RSI services. Twelve model families support
profiles, preferences, needs, saved matches, run history, audit/subscription metadata
and source snapshots. Four deterministic service stages read the stored inputs,
retrieve both graph trees and persist a human-review result.

The public funding corpus includes 18 dated institution/program references.
Their scope is source verification, not confirmation of open funding. Primary
government/institution sources take precedence over guessed terms. HAX's source
has inconsistent amounts across sections; ticket values remain unknown.

Compliance claims distinguish reporting, company response, allegations and analysis.
The Xiaohongshu media dispute is not converted into a confirmed violation.

## Failure learned

An immediate server termination after the successful match response exposed a
commit-after-response race. Fix: FastAPI function-scoped database dependencies,
committing before returning success. The regression uses two real Uvicorn processes
and checks company, match and Agent runs after restart.

## Principle

Private data + public evidence + inspectable reasoning. Unknown is not zero,
missing evidence is not approval, and a related controversy is not a guilt finding.
Current rules and retrieval are deterministic, with no runtime LLM calls.
