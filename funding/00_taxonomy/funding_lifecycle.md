# Funding Lifecycle

Discover category -> ingest bounded source material -> validate schema -> review source claims -> compare company readiness -> select explicit offer policy -> bilateral evidence audit -> inspect A2A trace -> human review -> record next action.

Downstream introduction, meeting, diligence, negotiation and funding decision remain human processes. The sandbox records requests but sends nothing and executes no funding transactions.

Profile status: scaffold (partial) -> provided (claims with provenance). Synthetic is a separate fixture designation, not a higher lifecycle stage. No user can assign a VERIFIED status. verified_at remains null until a separate verification workflow is implemented. Sources carry observed dates and claim scope; viewing an about page is not full mandate verification.

Re-review stale sources. Version policy changes and invalidate old match actions while retaining historical traces. Real profiles require program-specific legal and commercial review; score never overrides exclusion, consent or evidence gaps.
