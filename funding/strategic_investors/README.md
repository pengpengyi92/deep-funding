# Strategic Investors

Commercial fit, channel access, conflicts and strategic rights can matter alongside capital. Do not merge commercial partnerships with investments.

Records use the shared [profile contract](../README.md) and [taxonomy](../00_taxonomy/README.md). Each entry must state category tags, provides_capital, capital_forms, resources, stages, geography, industries, requirements, exclusions, application route and timestamped sources. Unknown values remain null or unknown.

Profile JSON is canonical. Only sourced claims belong in real records; fictional demo entries are explicitly marked synthetic. Cross-category membership indexes a stable slug instead of copying a second record. The current explorer is a research sandbox, not an investor database or funding recommendation.
